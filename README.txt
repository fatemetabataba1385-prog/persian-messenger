========================================
  پیام‌رسان فارسی ساده (گروهی)
========================================

این یک پیام‌رسان وب ساده است که:
- از زبان فارسی کامل پشتیبانی می‌کند
- چند نفر (حتی بیشتر از ۳ نفر) می‌توانند همزمان چت کنند
- متن، عکس و گیف می‌توانید بفرستید
- از هر جایی در دنیا با اینترنت کار می‌کند (نیاز به هاست دارد)

----------------------------------------
اگر برنامه‌نویسی بلد نیستید:
----------------------------------------

بهترین و ساده‌ترین راه برای شما این است که از برنامه‌های آماده استفاده کنید:

۱. تلگرام (پیشنهاد اصلی)
   - کاملاً رایگان
   - پشتیبانی عالی از فارسی
   - گروه بسازید و دوستانتان را اضافه کنید
   - عکس، فیلم، گیف، فایل، ویس و ... همه چیز را می‌فرستد
   - از هر فاصله‌ای کار می‌کند

۲. واتساپ
   - گروه بسازید
   - خیلی ساده است

۳. سیگنال یا دیسکورد
   - گزینه‌های خوب دیگر

اگر واقعاً می‌خواهید این کد را اجرا کنید، ادامه را بخوانید.

----------------------------------------
چطور این پیام‌رسان را اجرا کنید؟
----------------------------------------

گزینه ۱ (ساده‌ترین برای تست روی کامپیوتر خودتان):

1. برنامه Node.js را از سایت زیر نصب کنید:
   https://nodejs.org
   (نسخه LTS را دانلود و نصب کنید)

2. این پوشه (messenger) را روی کامپیوتر خود کپی کنید.

3. داخل پوشه، کلید Shift را نگه دارید و راست‌کلیک کنید، 
   سپس "Open PowerShell window here" یا "Open in Terminal" را بزنید.

4. این دو دستور را یکی‌یکی بنویسید و Enter بزنید:

   npm install
   npm start

5. مرورگر را باز کنید و بروید به:
   http://localhost:3000

حالا می‌توانید چند تب مرورگر باز کنید و با نام‌های مختلف وارد شوید و تست کنید.


گزینه ۲ (برای استفاده واقعی از راه دور - نیاز به اینترنت دارد):

باید این برنامه را روی یک سرور رایگان قرار دهید.
سایت‌های رایگان مثل:
- Render.com
- Railway.app
- Fly.io

مراحل تقریباً این‌طور است (کمی زمان می‌برد):
1. حساب رایگان بسازید
2. پروژه جدید از روی این پوشه بسازید
3. دستور start را npm start بگذارید
4. لینکی که به شما می‌دهند را به دوستانتان بدهید

اگر خواستید کمک کنید تا قدم‌به‌قدم روی یکی از این سایت‌ها بگذارید، بگویید.


محدودیت‌های این نسخه ساده:
- عکس حداکثر ۵ مگابایت
- فیلم کامل پشتیبانی نشده (فقط عکس و گیف)
- پیام‌ها ذخیره نمی‌شوند (اگر صفحه را رفرش کنید پاک می‌شوند)
- برای استفاده طولانی‌مدت بهتر است از تلگرام استفاده کنید
